# 盈利修正窗口与顶部预警：检验方案

制定日期：2026-10-19。先固定方案，再运行结果。研究文件独立保存，不修改页面的生产算法。

## 主检验

- 只比较基础修正窗口 L = 4、8、13、26、52 周。
- 数据：本地 FactSet 周报原始远期 EPS、当期已公布的 g_next，及 `_nasdaq.csv` 日收盘价。
- 逐周截断周报，再调用已有 `realtime.guard`，不使用后来才确认的 EPS 或年初的未来增长率回填。
- g_next 仅向前沿用最近公开值；跨年沿用是滚动扣除近似，不代表同目标年度的精确纯修正。首次公开值以前不计算纯修正。另做原始 EPS 变化、不扣滚动的对照。
- 所有窗口在共同可用数据上开始维护波段状态；2018-01-01 起评价。
- 主触发规则沿用大波段：从上轮低点上升 >=4c 个百分点，峰值 >=2c%，从峰值下降 >=2c 个百分点时发出警报；只用确认日，不能把峰值日期当可知日期。警报至少间隔13周。
- 周五周报信号保守地视为下一交易日收盘才可执行，以该日计算提前周数；信号当日恰为顶部不算提前。
- c 仅用2018—2020年信号频率，从固定集合 {0.25,0.5,0.75,1,1.5,2,3,4} 校准到约每年一次；不看任何价格结果。距离相同选较大的 c。锁定后评价2021年起的数据。
- 主目标：纳斯达克综合指数日收盘的10%对称Zigzag峰值，且峰后13周内确实跌满10%。不用手工排除熊市反弹中的顶部。
- 主预警范围：真实峰值之前、最多8周；峰后信号不给提前预警的功劳。同一峰值至多匹配一个警报，优先匹配距离峰值最近的警报；其余未命中的警报计入预警负担。
- 主结果：捕获顶部个数/总数、警报命中率、误报次数/年、领先周数。并给出每个顶部与每个警报的日期。
- 评价截止日固定为日线末日减去21周（8周找峰+13周确认跌幅）；统一取此前最后一个周五。召回率目标峰值截止该日，警报精确率允许匹配其后8周的完整已知峰值。

## 预先指定的稳健性检查

- 相同警报，对纳斯达克100、15%峰值回撤和提前13周窗口复核；按各组合的完整观察要求截断。
- 与未缩放 c=1 的生产规则、原始 EPS 变化、固定8周加速度转弱（滞回阈值同样只按训练频率校准）对照。主结论不能从这些附表里另挑赢家。
- 2021—2022、2023年起分别报告；另剔除2022年顶部，防止一次熊市周期主导结论。
- 循环平移全部五条警报序列，保留信号数量及聚集结构；排除不足26周的平移，计算单窗口与五窗口取最大值后的探索性置换概率。时间序列非平稳，不能把此概率视为强因果证据。
- 给出Wilson捕获率区间与留一顶部结果，明确事件不是独立样本。

## 解释边界

历史时点数据由保存的周报重建，仍不是完整的商业供应商逐日版本数据库；结果属于回顾性研究。时间留出能减少本次选参偏差，但过去已经看过这段市场历史，不能称全新前瞻验证。标普500盈利预期与纳指价格也不是同一成分股集合。13周差分不是严格微分；本次首先比较基础修正窗口，二阶导仅作附表。

研究后不得仅凭全样本第一名更改生产窗口；必须同时检查留出期、误报负担、标签敏感性及相对于同频随机时点是否有优势。

## 首轮计算后的完整性补充（不改变主检验）

首轮检查发现，13周内跌满的标签会排除2023年和2025年部分较慢下跌。追加26周跌幅确认窗口，只作敏感性检查；参数不重新选择，主表仍保留原定义。其截止日相应提前到日线末日减去26+预警周数。剔除2022年检查同时删除2022年的警报和目标，并从观察年数扣除该年。

独立审查补充：捕获率分母排除评价起点后不足8周（13周预警附表为13周）的顶部，确保每个目标都有完整提前观察机会；但警报命中率仍可正确计入起点后信号对早期顶部的成功预警。因此两种指标的成功数可能不同。2021-02-12属于这一左边界情形。置换捕获数采用同样的完整目标范围。
